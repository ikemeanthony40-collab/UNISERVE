# UNISERVE — Phase 1 Mission Engine

Competition track: **The Taskmaster**

This is the local foundation of UNISERVE. It accepts one high-level objective,
creates a multi-step mission, executes dependent tasks, deliberately encounters
a venue failure, detects the exception, replans, and continues to completion.

Run from this folder:

    python -m backend.main

Phase 2 will add Google ADK + Gemini, Firestore, Pub/Sub, Cloud Run and Mission Control.
